# 動画制作・運用の命令文集

CLAUDE.md に「動画の制作・運用前にマニュアルと台帳を読む」と書いてあるため、新しいセッションでも短い依頼でルールに沿って動きます。

## 1. 最初の1回（チャンネル設定）

```
動画チャンネルの設定を進めてください。候補はすべて推奨でOKです。
channels/ にチャンネルフォルダを作り、初回の企画候補3件まで出してください。
```

推奨案を変えたいときは「テーマは②、尺は12分」のように書き足します。

## 2. 毎回の作業を始めるとき（いちばんよく使う）

マニュアル記載の定型文：

```
本書とこのチャンネルの設定・台帳・最新承認・修正履歴を読み、未完了案件を優先してください。今日の対象曜日と実行中ジョブを確認し、許可された次工程を進め、成果物と次の行動を台帳へ記録してください。既知の承認待ちや変化なしでは通知しないでください。
```

短縮版：

```
動画の運用を再開して。台帳の続きから進めて
```

## 3. 工程ごとの依頼

| やりたいこと | 命令文 |
|---|---|
| 企画を出す | `次の動画の企画候補を3件と推奨1件、根拠付きで出して` |
| 承認する | `企画は案②で承認します`／`タイトルは推奨案で承認` |
| 台本を作る | `承認済みの企画で台本を作って、内容QAまで通して` |
| 試作を作る | `30〜60秒の試作を作って。費用の見積もりを先に出して` |
| 本編を作る | `承認済みの台本で本編を制作して。完成したら品質チェックリストで自己検査して` |
| 完成を承認する | `動画○○の完成版を承認します。公開は○月○日20時でOK` |

## 4. 修正をお願いするとき

```
（修正内容）を直してください。今後のすべての動画に適用（または「今回だけ」）してください。
```

適用範囲を書くと `feedback.md` に記録され、次の動画でも同じ失敗を防げます。マニュアル末尾の「すぐ使える修正依頼文」（画面が単調なとき、字幕が読みにくいとき、CMを差し込むとき、サムネイルが似てしまうとき）もそのまま使えます。

## 5. 公開後の分析

```
動画○○の公開7日後の数値です（表示回数○、CTR○%、平均再生率○%）。analytics.csv に記録して、改善案を1〜3件出してください。
```

YouTube が未接続のため、数値は YouTube Studio から貼り付けます。

## 6. 品質チェックだけ別に頼むとき

マニュアル記載の定型文。別セッションで頼むと、制作者とは独立した確認になります。

```
制作担当の要約だけで判定せず、設定・最新承認・見本・過去の修正と納品実ファイルを照合してください。冒頭・中盤・終盤・CM接続を含め全編を確認し、不具合は時刻、問題、期待結果、修正後の再検査結果で返してください。未確認を合格とせず、審査した版を特定してください。
```

## 7. 制作担当へ渡すとき

マニュアル記載の定型文：

```
承認済みの企画・タイトル・サムネ・台本版、選択型、音声、素材、場面対応表、過去の修正、承認見本を読み、指定出力先に新しい版で制作してください。全編の声・図・動きを対応させ、後半の品質チェックを自己検査してください。完成動画と検査記録を渡し、投稿は行わないでください。
```
