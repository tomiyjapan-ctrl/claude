# PR動画 モデル使い分け(Seedance 2.5 / MiniMax H3 / Kling 3.0)

## 0. 共通ルール(必ず守る)
1. **生成前に必ずクレジット見積もりを提示し、ユーザーのOKを得てから実行する。**
   `generate_video` に `get_cost: true` を付けて実額を確認する(推測で書かない)。
2. 会社名・商品名・ロゴ・パッケージ形状を出さない指定があるときは、プロンプト末尾に必ず:
   `Strictly no logos, no brand names, no labels, no packaging, no bottles, no pouches.`
   商品は「無地のグラス」「液体」「雫」「テクスチャ」で抽象的に表現する。
3. 主役は商品。人物は脇役 → `the product stays in sharp focus in the foreground; she is softly secondary`。
4. YouTube=16:9、Instagram=9:16 を別生成(構図を作り直す。単純クロップしない)。
5. 薬機法・健康増進法: 「治る」「若返る」「シミが消える」等の効能断定は文字・ナレーションに入れない。
   化粧水は「うるおい」「ハリ・ツヤ」「肌を整える」の範囲、飲料は「毎日の健康習慣」「内側から」程度に留める。
6. 納品物: 動画 + タイトル + 説明欄 + ハッシュタグ + タグ(YouTube用/Instagram用それぞれ)。

## 1. モデル早見表

| | Seedance 2.5 | MiniMax H3 | Kling 3.0 |
|---|---|---|---|
| model id | `seedance_2_5` | `minimax_h3` | `kling3_0` |
| 長さ | 4〜30秒 | 4〜15秒 | 3〜15秒 |
| 解像度 | 480p/720p/1080p | 2K固定 | std / pro / 4k |
| 強み | 1プロンプトで多カット構成、ネイティブ音声(BGM/SE)、文字表現、下書き→本番化、動画編集・延長 | 2Kの高精細、開始/終了フレーム指定、画像・動画・音声の混合参照 | マルチショット、音声同期、モーション転写、安定した人物の動き |
| 向く用途 | 15秒CMを1本で完結 / 構成・テロップ・音まで作り込む | 商品キービジュアルからの高精細な動き / 指定フレームで始めて終える | 人物の演技・リップシンク・動きの自然さ重視 |
| 15秒の実額(2026-10確認) | 下書き480p **45** → 1080p本番化 **60**(計105)/ 直接1080p 180 / 720p 105 | **30**(2K) | std+音声 **30** / pro は要 get_cost |

**選び方**
- 15秒の完成CMを1発で、文字・BGM・SEまで → **Seedance 2.5(下書き→本番化)**
- 商品の静止画キービジュアルを高精細に動かす / 始点・終点を厳密に決めたい → **MiniMax H3**
- 人物の自然な演技・表情・口の動きが重要 / 複数カットを個別に制御 → **Kling 3.0**
- 迷ったら素材を MiniMax H3 / Kling 3.0 で安くカット生成 → 編集で繋ぐ、も可。

## 2. Seedance 2.5 の指示の書き方
- **下書き(`draft: true`, 480p, 45cr)で構図・テロップ・音を確認 → 良ければ `draft_job_id` で1080p本番化(60cr)。** 1080p直接(180cr)より安く、失敗コストも小さい。
- タイムコード付きショットリストで書く: `Shot 1 (0-2s): ...`
- 15秒CMの型: **フック(0-2s)→ 問題提起/コンセプト(2-5s)→ 商品の科学的・感覚的ビジュアル(5-9s)→ 人物の体験(9-12s)→ 商品ヒーロー+キャッチコピー(12-15s)**
- カット数は 6〜8 程度、カメラワークを毎カット指定(macro push-in, orbit, rack focus, speed ramp, whip pan)。
- **文字**: `Large elegant on-screen Japanese text appears: 「…」` と鉤括弧で正確に指定。1カット1フレーズ、10文字前後まで。長文は崩れやすい。
- **音**: `Audio:` 節で BGM のジャンル・テンポ・盛り上がる位置、SE(注ぐ音、泡、きらめき、ウーシュ)をタイムコード付きで指定。ナレーションを入れない場合は `no spoken dialogue`。
- `generate_audio: true` を必ず付ける。
- 16:9 と 9:16 は別プロンプト(9:16 は縦構図・人物と商品を縦に重ねる・文字は中央上寄せ)。

## 3. MiniMax H3 の指示の書き方
- `medias` に `start_image`(必要なら `end_image`)を渡し、キービジュアル(`gpt_image_2_5` / `marketing_studio_image` で作成)から動かすのが基本。
- プロンプトは**1カット1動作**で短く: カメラの動き + 被写体の動き + 光の変化。多カットを詰め込まない。
- 2K出力なので、液体・雫・肌の質感のクローズアップに向く。
- 文字は入れず、テロップは編集で後乗せ前提。

## 4. Kling 3.0 の指示の書き方
- `mode`: `std`(安い)/ `pro`(高品質)/ `4k`。`sound: "on"` で音声同期。
- 人物の演技指示を具体的に: 視線、表情の変化、手の動き、呼吸のタイミング。
- マルチショットは各ショットを短い文で区切る。`start_image`/`end_image` で人物の一貫性を担保。
- 商品主役のときも、人物カットは Kling・商品カットは MiniMax H3 と分担すると品質が安定する。

## 5. 作業手順
1. 商品情報・過去例を確認(YouTube は `video_analysis_create` で構成分析)。
2. 構成案とモデル選定 → `get_cost` で見積もり → ユーザーのOK。
3. 下書き(Seedance)/ カット生成(H3・Kling)→ ユーザー確認。
4. 本番化 → 納品物(タイトル・説明欄・ハッシュタグ・タグ)を作成。
